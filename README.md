# 🎵 PromoDJ Music Downloader 🎵

![App Screenshot](_other/screenshot.png)

This application provides a **convenient way** to download tracks, mixes, and live sets directly from [PromoDJ](https://promodj.com) - *the best place for electronic music lovers! 🎧*


✨ **Key Features:**
*   **Fully portable**
*   **User-friendly** interface
*   **History** of downloaded files (if enabled)
*   Completely reworked and rewritten into **Rust** code
*   This one much more **site-friendly** than older versions
*   New **filtering** features (XF - Exclusion filter, IF - Inclusion filter)
*   New **proxy** feature (http/s, socks5)
*   New **UI Scale** feature (x1.00-x4.00)
*   **Multi-OS** support (Windows, Linux, MacOS)
*   **Multi-language** support (En, Ru, Uk)

❤️ **Enjoy!**
